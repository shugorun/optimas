# evergreen の差し戻し規則（merge × 成熟度）

収束的リンカ（ADR-0001）により、evergreen ノートも昇格後に変化しうる（後から merge・リンク・矛盾が付く）。差し戻しの規則を変化の種類で場合分けする：

1. **リンク追加のみ**（被リンク／発リンク）→ 据え置き（主張不変）。
2. **同一命題の裏付け provenance 追加**（corroborating merge）→ 据え置き（出典が増えるだけ）。
3. **主張が変わる merge/編集** → **draft に差し戻し、再卒業**。
4. **新しい矛盾（contradicts）の出現** → 据え置き＋**人間レビューのフラグ**。

理由：どんな変化でも差し戻すと、能動的に取り込み続ける限り evergreen が永久に安定しない。逆に一度 evergreen なら不変だと、主張が変わった後も「完成」の嘘ノートが残る。変化の種類で分けることで「evergreen＝安定だが改訂可能」を保つ。矛盾の出現はジョブ1（理解が育つ）の最重要イベントなので、差し戻さずフラグで surface し、人間が解決を選べるようにする。
