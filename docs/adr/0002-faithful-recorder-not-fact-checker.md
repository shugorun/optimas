# 真偽検証はスコープ外（忠実な記録装置であってファクトチェッカーではない）

システムは各ソースが何を主張したかを出典つきで忠実に記録するだけで、主張の真偽は検証しない。真偽は読むときに人間が判断する。

理由：(1) 任意の主張の検証は事実上無限のオープン問題で、LLM による検証は信頼できない。(2) 個人知識ベースの atom には検証不能なもの（意見・総合・枠組み）が多い。(3) 最優先ジョブ「理解が育つ」にとっては、誤解を黙って訂正されるより、自分の信念と権威ある主張の食い違いを矛盾リンクとして提示される方が価値が高い。検証の代わりに矛盾検出（contradicts リンク）を一級機能とする。
