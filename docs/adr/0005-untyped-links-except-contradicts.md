# リンクは無型＋散文を既定、contradicts のみ機械可視な型付き

ノート間リンクは原則 `[[id|タイトル]]` の無型とし、関係（根拠・対処・具体例…）はリンク周りの散文で表現する（Andy Matuschak 流）。例外として `contradicts`（矛盾リンク）のみ、機械パース可能な型付き表現（frontmatter のリストまたは Dataview inline フィールド）で持つ。

理由：全リンクを関係タクソノミーで型付けるのは Obsidian 非ネイティブで設計・維持コストが高く、最優先ジョブ1（読んで理解が育つ）には散文の文脈で十分。一方 contradicts はジョブ1の中核トリガーであり、Gold に含め、ルーブリック M1（矛盾を merge していないか）の判定にも使うため機械可視が必須。優先順位（ジョブ1 ≫ ジョブ3 再発見・ジョブ4 検索）から、グラフの機械的リッチさを得るための型タクソノミーは見送る。
