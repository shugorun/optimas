# Gold は制約の集合、評価は較正済みアラインで行う

Gold を「唯一の正解ノートグラフ」ではなく、**存在すべき命題（意味単位）＋それらの関係（リンク／矛盾／merge）＋ルーブリックラベル**という制約集合として定義する。評価時は、出力ノートを Gold 命題へ意味アライン（較正済みジャッジまたは埋め込み一致で「この出力ノートは Gold 命題 P を表すか」を判定）してから、リンク・矛盾・merge の充足とルーブリック合格を測る。文字列一致は要求しない。

ただし **granularity（粒度）は atomicity ルール（独立参照テスト＝ルーブリック A1）で一意に固定**し、許容するのは phrasing の違いのみとする。

理由：LLM 抽出は非決定的で、同じ命題を正しく表す書き方は無数にある。唯一の正解テキストにすると、正しいが書き方の違う出力を全て fail にしてしまう（生成物評価のアンチパターン）。アライン自体は誤差源だが生成物評価では不可避であり、ADR-0004 の人間較正をアライン判定にも適用して信頼性を担保する。
