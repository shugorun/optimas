# リンカは2段（recall リトリーバル → precision 分類）、手法は実装に委譲

リンカは2段構成とする：(1) リトリーバル（候補生成・recall 重視・広い網）→ (2) 4分岐分類（NEW/MERGE/CONTRADICTS/LINK・precision 重視・枝刈り）。リトリーバルは、ノート増大時に全件比較を避ける**スケーラビリティ**と、cross-source リンクの**recall 確保**の両方を担う。具体シグナル（hybrid＝埋め込み＋語彙 を推奨）と候補数 k は、凍結コーパスの Gold に対して経験的にチューニングし、実装に委譲する。

帰結（記録の主目的）：**cross-source リンクの recall はリトリーバルの recall を超えられない（天井）。** ゆえに retrieval recall を一級メトリクスとして独立に測定し、リンク recall が低いときの第一診断点とする。後段の分類器をいくら直しても、リトリーバルが候補に挙げ損ねたリンクは回復できない。
