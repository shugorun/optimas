# タイトルは claim-title、リンクは安定 ID 経由

ノートのタイトルは原則として完全な主張文（claim-title）とし、純粋な定義ノートのみ概念ハンドル（concept-handle）を許す。リンクはタイトルではなく不変の安定 ID（ファイル名＝ID、表示は `[[id|タイトル]]`）で張る。

claim-title は「1ノート1主張」を物理的に強制し、最優先ジョブ（理解が育つ）に効く。一方、収束的リンカ（ADR-0001）では主張の洗練・merge でタイトルが頻繁に変わるため、「ファイル名＝タイトル」の素朴形だとタイトル変更のたびに全被リンクの書き換えが走り、書き換え漏れ＝リンク切れが「リンク完全性」テストを脅かす。安定 ID なら ID 不変ゆえタイトルが変わってもリンクは壊れない。代償は、フォルダ上のファイル名が人間に無意味になること、リンク表記が `[[id|タイトル]]` と1段冗長になること。
